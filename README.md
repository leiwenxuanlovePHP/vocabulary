# 单词拼写系统
>by LeiwenxaunlovePHP
 
## 这是什么？
我改编(面目全非)的小项目

原项目地址[在这](https://www.luogu.com.cn/article/6e9oigg1)，实在看不惯，就加了点小东西

## 怎么用？
### 下载：
```bash
git clone https://github.com/leiwenxaunlovePHP/vocabulary
cd vocabulary
```
### 运行：
```bash
python vocabulary.py
```

---
**成功后会正常显示如下界面：**

![bocuo](https://cdn.luogu.com.cn/upload/image_hosting/libsxrde.png)

### 添加词书 
你可以自己写词书，也可以用我给的`vocabulary.json`词书

点击`添加词书`将词书导入

再点`开始听写`来做题，正确率会统计显示出来
